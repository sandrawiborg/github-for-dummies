# GitHub for dummies

Dette er mitt første repository, opprettet som en del av kurset **GitHub for dummies**. Her øver jeg på å bruke GitHub, ett steg om gangen.

## Formål

Dette repoet er en øvingsplass for å lære å:

- Opprette og redigere filer på GitHub.
- Lagre endringer med tydelige commit-meldinger.
- Bruke branches for å jobbe med endringer uten å endre hovedversjonen.
- Foreslå og diskutere endringer gjennom pull requests.

## Innhold

Foreløpig inneholder repoet denne README-filen. Flere filer og øvelser kan komme til etter hvert som jeg lærer mer.

## Prøv selv

Du trenger bare en GitHub-konto og en nettleser for å komme i gang i ditt eget repo:

1. Åpne `README.md` og trykk på blyantikonet for å redigere.
2. Skriv en kort tekst, for eksempel noe du har lært.
3. Velg **Commit changes**, og skriv en melding som forklarer endringen.
4. Velg å opprette en ny branch, og foreslå endringen med en pull request.
5. Se gjennom endringen før du slår den sammen med `main`.

## Nyttige begreper

| Begrep | Forklaring |
| --- | --- |
| Repository (repo) | Et prosjekt med filer og historikken over endringene. |
| README | En introduksjon som forklarer hva prosjektet er og hvordan det brukes. |
| Commit | En lagret endring med en melding om hva som er gjort. |
| Branch | En egen utviklingslinje der du kan jobbe uten å endre hovedversjonen. |
| Pull request (PR) | Et forslag om å slå sammen endringer fra én branch til en annen. |
| Merge | Å slå sammen endringer, for eksempel fra en branch til `main`. |
